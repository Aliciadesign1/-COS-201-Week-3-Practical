# COS 201 - Week 3 Practical Exercises

## Introduction
This repository contains Java programs completed for the COS 201 Week 3 practical exercises.

## Programs

1. SimpleCalculator.java - Performs addition, subtraction, multiplication and division of two numbers.
2. AverageCalculator.java - Accepts a student's name and three scores, then calculates the total and average.
3. ItemCost.java - Calculates the total cost of an item using its quantity and unit price.

## Requirements
- Java Development Kit (JDK)

## How to Run

Compile and run each program using the following commands:

### Simple Calculator
javac SimpleCalculator.java
java SimpleCalculator

### Average Calculator
javac AverageCalculator.java
java AverageCalculator

### Item Cost
javac ItemCost.java
java ItemCost
